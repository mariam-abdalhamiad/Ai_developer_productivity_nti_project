AI Developer Productivity Prediction

Project Overview

An end-to-end Machine Learning project developed as part of the NTI Training Program to predict AI developers’ task success based on productivity metrics and coding-related factors.

Project Workflow

* Data Cleaning & Preprocessing
* Handling Missing Values & Outliers
* Exploratory Data Analysis (EDA)
* Feature Engineering & Feature Scaling
* Model Training using Logistic Regression and Random Forest
* Hyperparameter Tuning & Model Evaluation
* Performance Comparison
* Model Deployment using Flask

Technologies & Tools

* Python
* Pandas & NumPy
* Scikit-learn
* Logistic Regression
* Random Forest
* Flask
* Joblib

Key Learning Outcomes

* End-to-end Machine Learning development.
* Data preprocessing and feature engineering.
* Classification model training and evaluation.
* Model optimization and performance comparison.
* Machine Learning deployment using Flask.

Project Goal

To apply Machine Learning techniques to analyze developer productivity and predict task success through an interactive web application.


Developed as part of the National Telecommunication Institute (NTI) Training Program.
